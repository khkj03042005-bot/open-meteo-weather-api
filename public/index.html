카드 5 — 실제 이틀과 어제 대비

서로 다른 한국 날짜의 실제 기록 2개가 쌓이면 비교합니다.

아직 비교할 실제 날짜별 기록이 2개 없습니다.
  • 서로 다른 Asia/Seoul 날짜의 실제 공개 원천 기록 2개 보관
  • 각 기록의 원천 URL, 관측 시각, 단위 표시
  • 두 기온 값으로 어제 대비 변화를 다시 계산

짧은 확인 순서

  1. 웹사이트에서 실제 API를 호출해 첫 날짜의 기록을 저장합니다.
  2. 다른 KST 날짜가 된 뒤 실제 API를 다시 호출하고 날짜별 기록을 확인합니다.
  3. 카드에 두 날짜, 원천 URL·관측 시각·단위, 어제 대비 기온 차이가 보이면 통과입니다.

통과하지 않을 때: 기록이 1일뿐이면 두 번째 날짜가 아직 없다는 안내가 보입니다. 원천 정보가 비어 있거나 단위가 다르면 해당 정보 없음 또는 비교 불가로 확인해야 합니다.

제출 시 확인 메모

  • AI에게 맡긴 일: 카드 5 화면·원천 정보 보존·기온 차이 계산 기능 구현
  • 학생이 직접 판단한 일: 실제 날짜가 다른 기록 2건인지, 화면 값과 원천 관측값이 일치하는지 확인
  • AI 제안을 따르지 않은 일: 없었다면 ‘없음’, 있었다면 무엇을 제외했는지 직접 작성
